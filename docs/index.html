Why this is manual. The Google Indexing API accepts our URLs (HTTP 200) but keeps no record of them — urlNotifications/metadata returns 404 for every one, including URLs pushed five weeks ago on tryretafit, osanix and ozem-plus. It officially supports only JobPosting and BroadcastEvent pages. The sitemap is submitted and Google fetched it (18 URLs, 0 errors); Request Indexing in Search Console is the only way to push individual pages up the queue.
How to run it
  1. Open Search Console and select the wellaray.shop property.
  2. Press Copy on the first row, paste it into the URL Inspection box at the top, press Enter.
  3. Click Request Indexing, wait for the confirmation, then tick the row here.
  4. Google limits how many you can request per day. When it stops accepting, stop — your progress is saved in this browser, so you can carry on tomorrow from the first unticked row.
Use more than one Google account — the quota is per user, not per site
  1. In Search Console → Settings → Users and permissions, add each new Gmail as an Owner on wellaray.shop.
  2. Each owner gets their own daily Request-Indexing allowance. Four owners working in four browser profiles submit roughly four times as many URLs a day.
  3. Split this list between them by country block so nobody submits the same URL twice — give one person Deutschland, another the UK, and so on.
  4. Ticks are saved per browser, so each person keeps their own progress.
